## 3. What the circle can still be

After gravity is off, \(\tau_{\rm web}\) has to be one of these, and you must pick:

**A. A 4D coherence / correlation length.**  
No fifth direction at all. Galaxies and filaments know about \(\sim 7h^{-1}\,\mathrm{Mpc}\) the way they know about any clustering scale. \(\mathcal K_{ij}\) or embedding shear may set it. This is Superblock-native. Calling it a “circle” is optional poetry.

**B. An internal phase circle.**  
A label \(\phi\sim\phi+2\pi\) with a spatial fossil of that size. Gravity does not wrap \(\phi\). Maxwell need not wrap \(\phi\). Occupations on an atemporal menu may. This is the helix / substratum reading.

**C. A circle that some *other* field wraps.**  
A scalar, a Tav field, a resonance current \(\psi_\tau(x,y)\). Then you have a fifth-force problem instead of a gravity problem: does \(\psi_\tau\) couple to baryons? To photons? To the stress that sources \(\mathcal K_{ij}\)? If it couples enough to build a galaxy power-spectrum comb, the March 2026 JADES/DESI nulls still apply. If it couples too weakly to be seen there, it is not explaining the web either.

**D. A purely formal \(S^1\) that nothing wraps.**  
Then it is not doing physics. Drop the name.

A and B are the only versions that both drop gravity *and* stay compatible with this session’s SBT charter. C is a new theory with new bounds. D is scenery.
