## 0. Verdict

**The idealization is right. The census is not quite.**

A exactly nonrotating vacuum hole is a set of measure zero. Every astrophysical source has some angular momentum, so the exterior that carries spin is Kerr, and the singularity locus of that family is the ring. Schwarzschild remains the \(a\to 0\) limit, and a hole with \(a/M\) below the measurement floor is operationally Schwarzschild. “All real objects rotate” does not mean every horizon has an observationally resolved ring, and it does not put seeds inside the ring.

## 2. What is fair

Birkhoff’s theorem says the vacuum exterior of a spherical nonrotating collapse is Schwarzschild. Real stars, planets, and collapse remnants have angular momentum, so \(a=0\) is an idealization. The rotating vacuum exterior is Kerr (Kerr–Newman if charge is kept). In that family the curvature singularity is the ring, not the Schwarzschild \(r=0\) set. A static Schwarzschild singularity is not the expected end state of a generic collapse.

The live frame already refuses a static event horizon as the physical locus. The seam is apparent. The Mirron is a Planck–Kerr mirror, not a Schwarzschild point.

---

## 3. What does not follow

Small spin is allowed. A hole with \(a/M\) below what the shadow or the ringdown can see is fitted by Schwarzschild. The chart \(r_s=2GM/c^2\) remains the saturation test for a glob, spin corrections aside. “Every object has angular momentum” is also true of the Earth, which is not a horizon and not a ring singularity.

The ring of a Kerr hole is still the circle of intrinsic dimension \(1\), sitting in a plane. It is not six Planck seeds, and the disk center is still the regular throat.
