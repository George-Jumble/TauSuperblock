# \(R_{\rm int}\) — the unnamed radius

**Date:** 2026-09-20  
**Fact:** F7 freezes exponent \(1\) as the *radius slot*. That stops \(R_{\rm int}\) running. It does not output a metre.  
**Forbidden:** \(R_{\rm int}=7\,h^{-1}\,\mathrm{Mpc}\), or any mint from exponent \(7\).

---

## 1. What is fixed

\[
\mathrm{Vol}(S^3_{\rm int})=2\pi^2 R_{\rm int}^3.
\]

Hopf fibres have length \(2\pi R_{\rm int}\). Geodesic spacing of six points is \(\sim R_{\rm int}\). None of that is a value.

**Key.** \(R_{\rm int}\): radius of \(S^3_{\rm int}\). Slot frozen. Value not frozen.

---

## 2. Three identifications that *do* give a number

**I1 — Planckian engine (recommended default).**  
The sphere is the same size as the Planck–Kerr ring that sits on it.

\[
R_{\rm int}=\ell_{\rm Pl}=1.616\times 10^{-35}\,\mathrm{m}.
\]

Hopf fibre \(2\pi\ell_{\rm Pl}\). Continuous KK modes, if they existed, would sit at \(M_{\rm Pl}\). Occupancy is already discrete, so those modes are off. No light extra dimension. \(m_0\) stays an independent floor.

**I2 — Floor Compton.**  
Identify the sphere with the kernel’s UV length.

\[
R_{\rm int}=\lambda_{m_0}=0.6302\,\mathrm{fm}=6.302\times 10^{-16}\,\mathrm{m}.
\]

Then \(R_{\rm int}/\ell_{\rm Pl}=3.90\times 10^{19}\). A *continuum* of modes on that sphere would be hadronic, i.e. visible. Allowed only because isometries are broken and occupancy is six points. This *identifies* \(m_0\) with \(\hbar/(R_{\rm int}c)\), so it is not a derivation of \(m_0\); it is a name of \(R_{\rm int}\). New axiom.

**I3 — Extremal Kerr parameter.**  
Ring radius \(a=GM/c^2\). For a Planck-mass extremal hole, \(a=\ell_{\rm Pl}\). Same number as I1 if the shared ring *is* the Hopf fibre. Same default.

There is no I4 from \(h\), \(|W|\), or \(\sum\gamma_i\). Those are dimensionless.

## 3. Decision

Live frame can adopt **I1**: \(R_{\rm int}=\ell_{\rm Pl}\), without touching \(m_0\) and without a megaparsec.
