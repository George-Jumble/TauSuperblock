# Session 2026-09-14 — Many gluons vs 313 MeV per gluon

**Point:** A glueball is several gluons bound together. That does **not** by itself make \(E_g=313.1\,\mathrm{MeV}\) incompatible with a glueball. It is incompatible with two specific predictions.

---

## 1. Complete symbol key

| Symbol | Meaning |
|--------|---------|
| \(E_g\) | Inertial energy assigned to one bound gluon quantum |
| \(\Delta_{\mathrm{Tav}}\) | \(313.1\,\mathrm{MeV}\) |
| \(n_g\) | Valence (or effective) gluon number in the state |
| \(V_{\mathrm{bind}}\) | Binding energy (\(<0\) if the quanta attract) |
| \(M_G\) | Glueball mass |
| \(M_{0^{++}}\) | Lightest scalar glueball |
| \(M_{2^{++}}\) | Lightest tensor glueball |

\[
M_G
=
n_g E_g
+
V_{\mathrm{bind}}.
\]

**Key:** mass is occupancy times quantum plus binding.

---

## 2. What is *not* disturbed

If \(E_g=313.1\,\mathrm{MeV}\) and \(n_g\) is large enough,

\[
M_{0^{++}}
\simeq
5\times 313.1\,\mathrm{MeV}
=
1565.5\,\mathrm{MeV}
\quad(V_{\mathrm{bind}}\approx 0)
\]

sits in the quenched lattice window \(\sim 1.6\)–\(1.7\,\mathrm{GeV}\).  
“Many gluons, each \(313\,\mathrm{MeV}\)” is then a **composition rule**, not a rival resonance at \(313\,\mathrm{MeV}\).

Quark dressing is the same quantum on a different state: \(n_g=1\) attached to a light quark.

---

## 3. What *is* disturbed

**A. The video prediction.**  
“Excess glueball at \(313\,\mathrm{MeV}\)” names the **glueball mass** as \(313\,\mathrm{MeV}\). That is \(n_g=1\), \(V_{\mathrm{bind}}=0\). A single gluon is not a glueball. That prediction is what conflicts with the definition and with the catalog.

**B. The standard two-gluon scalar.**  
The usual valence picture of the lightest \(0^{++}\) is **two** gluons. Then

\[
M_{0^{++}}
=
2E_g+V_{\mathrm{bind}}
=
626.2\,\mathrm{MeV}
+
V_{\mathrm{bind}}.
\]

**Key:** to reach \(1.6\,\mathrm{GeV}\) you would need \(V_{\mathrm{bind}}\approx +1\,\mathrm{GeV}\) (anti-binding / extra kinetic) or you must drop \(n_g=2\).

Constituent-gluon models that do use \(n_g=2\) typically take \(E_g\sim 600\)–\(800\,\mathrm{MeV}\) so that \(2E_g\sim 1.4\)–\(1.6\,\mathrm{GeV}\). Those models are disturbed by \(E_g=313\,\mathrm{MeV}\): the two-gluon scalar would land near \(0.6\,\mathrm{GeV}\), where there is no established glueball.

So the definition “many gluons” only saves \(313\,\mathrm{MeV}\) if **many** means \(\sim 5\) for the scalar (or \(2\) with a huge positive extra term). It does not save a pole at \(313\,\mathrm{MeV}\), and it does not save the default \(n_g=2\) assignment without changing \(E_g\) or \(V_{\mathrm{bind}}\).

## 4. Occupancy table

| \(n_g\) | \(n_g E_g\) | If this is \(M_G\) |
|--------|-------------|---------------------|
| 1 | \(313\,\mathrm{MeV}\) | dressing quantum; not a glueball |
| 2 | \(626\,\mathrm{MeV}\) | naive \(0^{++}\); **too light** vs lattice |
| 3 | \(939\,\mathrm{MeV}\) | three-gluon / oddball toy; still light |
| 5 | \(1.57\,\mathrm{GeV}\) | matches \(0^{++}\) window |
| 8 | \(2.50\,\mathrm{GeV}\) | near \(2^{++}\sim 2.4\,\mathrm{GeV}\) |

---

## 5. Rule

- Keep \(E_g=313.1\,\mathrm{MeV}\) as the quantum.  
- Do not predict a glueball **at** \(313\,\mathrm{MeV}\).  
- If you predict the lattice scalar, state \(n_g\) (and \(V_{\mathrm{bind}}\)) explicitly. \(n_g=2\) fights \(E_g=313\,\mathrm{MeV}\); \(n_g\approx 5\) does not.
