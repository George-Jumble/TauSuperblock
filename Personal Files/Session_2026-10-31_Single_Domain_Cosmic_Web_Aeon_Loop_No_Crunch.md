   \mathbf{v}_i \propto \sum_j \lambda(\mathbf{x}_j)\exp(-|\mathbf{x}_i-\mathbf{x}_j|^2/\sigma^2)\,(\mathbf{x}_j-\mathbf{x}_i)

Only one observable domain is shown. Filament edges appear only while structure is present.
