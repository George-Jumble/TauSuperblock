## 0. Verdict

**Use a mass the protocol does not already divide.**

Best external QCD anchors: the pion decay constant, or the pion mass. Usable but easy to cheat: the string tension. Bad as anchors: \(\Lambda_{\overline{\mathrm{MS}}}\), the nucleon, the constituent up, \(W+Z\). The Yang–Mills gap and this floor are different operators. Do not anchor one on the other until both are named.

| Symbol | Meaning |
|--------|---------|
| \(\Delta\) | Working floor \(309.3\,\mathrm{MeV}\). Neutron dressing protocol. The thing to be derived, so not the anchor. |
| \(M_*\) | Anchor. Must not be \(\Delta\). |
| \(f\) | Clock function, still unwritten. Must be fixed before comparison. |

| \(\sqrt{\sigma}\) | String tension, lattice scale about \(440\,\mathrm{MeV}\). |

| \(M_{0^{++}}\) | Lightest scalar glueball, lattice about \(1.5\)–\(1.8\,\mathrm{GeV}\). A gap candidate. Not this floor. |

## 2. Ranked suggestions

1. Pion decay constant \(f_\pi\). Chiral scale. Not a nucleon third. Not a constituent quark. A clock derivation is \(f\,f_\pi\), with \(f\) written first, then compared to \(309.3\,\mathrm{MeV}\). A miss is allowed.

2. Pion mass \(m_\pi\). Measured to high precision. Same virtue. \(m_\pi\) is a meson mass, not the dressing of a valence line, so the operator still has to be named.

3. String tension \(\sqrt{\sigma}\approx 440\,\mathrm{MeV}\). A real QCD scale, independent of \(M_n/3\). Close enough to \(309\) that a fitted \(f\) near \(0.7\) would be suspicious. Usable only if \(f\) is published first.

4. Electron or muon mass. Maximally independent. A clock function would have to be large and would be testing a lepton-to-dressing ratio, not QCD binding. Honest, and likely to miss.

Not recommended:

- \(\Lambda_{\overline{\mathrm{MS}}}\). It is defined to sit at the QCD scale. Anchoring \(\Delta\) on it cannot fail in an interesting way.
- Nucleon mass, \(M_n/3\), \(M_p/3\), equal-share constituent up. These are the protocol.
- \(M_W+M_Z\). External, and \(555\) times the floor. Transmitter mass, not dressing.
- Planck mass. Uses \(G\). Cut stands.
- \(\tau\). Retired.

---

## 3. Gap versus floor

If “mass gap” means the Clay gap, the comparison object is a glueball or \(\sqrt{\sigma}\), not \(309.3\,\mathrm{MeV}\). If it means the Superblock floor, the comparison object is per-line dressing. Pick one before choosing \(M_*\). Anchoring the floor on the gap, or the gap on the floor, renames one unproved number as the other.
