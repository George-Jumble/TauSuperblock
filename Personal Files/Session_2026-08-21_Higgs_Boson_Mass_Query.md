## Result

The mass (commonly referred to informally as “weight”) of the Higgs boson is a fundamental free parameter of the Standard Model. The most precise recent experimental determinations (LHC Run 1 + Run 2 combinations, ATLAS and CMS) place it at approximately **125.1 GeV**.

### Latest reported values (2025–2026 literature)

- **CMS** (H → γγ + prior combination):  
  \( m_H = 125.14 \pm 0.11\,\text{(syst.)} \pm 0.10\,\text{(stat.)} \) GeV  
  Combined Run 1 + Run 2: \( m_H = 125.07 \pm 0.13 \) GeV

- **ATLAS** (H → γγ + H → 4ℓ combination, Run 1 + Run 2):  
  \( m_H = 125.11 \pm 0.11 \) GeV  
  (stat. 0.09 GeV, syst. 0.06 GeV)

- Older widely cited CMS combination (still referenced): \( m_H = 125.38 \pm 0.14 \) GeV

**Consensus working value** used in most contemporary phenomenology:  
\[ m_H \approx 125.10 \pm 0.11\,\text{GeV} \]

### Variable key (for the mass statements above)

| Symbol | Meaning |

| \( m_H \) | Rest mass of the Higgs boson |
| GeV | Gigaelectronvolt (energy unit; mass in natural units where \( c = 1 \)) |
| syst. | Systematic uncertainty |
