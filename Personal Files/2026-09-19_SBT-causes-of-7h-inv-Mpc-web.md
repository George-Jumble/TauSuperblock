## 1. First fact: ΛCDM already makes a web

Galaxy correlation lengths of order \(5\)–\(7h^{-1}\,\mathrm{Mpc}\), filament widths of order \(1h^{-1}\,\mathrm{Mpc}\), and void–web distances of several \(h^{-1}\,\mathrm{Mpc}\) appear in ordinary gravity plus cold matter plus baryons. SBT does not need to invent the web.

SBT only has a *cause of the scale* if it predicts a preferred comoving length, or a fracture statistic that is not just “where the density contrast is order one.”

Freeze the statistic before fitting 7. Example: median comoving distance from a non-web particle to the nearest filament spine, or the scale where \(\Pi_{\rm choke}\) peaks after shock heat is subtracted.

## 2. Causes that are allowed in SBT after today

None of these is a metric \(S^1\). None uses \(k=1/7\) as a discovery.

### A. Kernel coherence (best default)

\(\mathcal K_{ij}\) is not required to be strictly local. If the embedding average that lets domain \(j\) source domain \(i\) stays coherent only out to \(\ell_C\), then:

- below \(\ell_C\): other-domain stress looks like a smooth dark component,
- at \(\ell_C\): phase lock fails, flux redirects, the web “fractures.”

Then \(\tau_{\rm web}\sim\ell_C\) in comoving units if the kernel is defined on the expanding spatial sections.

This is the same object already needed for other-domain dark matter. One kernel, two jobs: sourcing and a scale. It does not derive 7 until \(\mathcal K\) is computed from \(V_{\rm orb}^{(i)}\) and the twistor / impulse average.

### B. Embedding shear from staggered \(V_{\rm orb}\)

Six domains on the supersphere with different orbital velocities. Relative embedding motion shears phase alignment. The comoving length at which accumulated shear across a patch reaches \(\mathcal O(1)\) is a web scale.

Schematic:

\[
\ell_C^{-1}
\sim
\frac{|\Delta V_{\rm orb}|}{c_{\rm emb}}
\cdot
\frac{1}{L_{\rm emb}}
\]

with \(c_{\rm emb}\) and \(L_{\rm emb}\) set by the supersphere map, not by a lab extra dimension. If the shear is locked to expansion, \(\ell_C\) can freeze in \(h^{-1}\,\mathrm{Mpc}\).

This is the most SBT-native kinematic cause. The arithmetic does not exist yet.

### C. Occupation-gradient on an atemporal substratum

If the harmonic law is frozen and only occupations \(N_\lambda(n)\) write, a spatial gradient in occupation (other-domain filling vs ours) has a correlation length. After the 4D read-out, that length is \(\tau_{\rm web}\).

Useful only if the substratum is already adopted. Do not introduce the substratum *in order* to explain 7.

### D. Conformal / twistor exhaustion

Local twistor average remains coherent only out to a finite reach. Beyond that, conformal coupling cannot bind a patch. That was the instinct in the “conformal exhaustion” note.

Keep it as a possible computation of \(\ell_C\), not as “exactly 7 because 142857.”

### E. Phase-7 mean path (secondary, thermal)

If Phase-7 flux thermalizes or fails to couple after a comoving path \(\lambda_7\), filaments heat where that path hits density ridges. That can *correlate* heat with \(\tau_{\rm web}\). It should not be the definition of the web. Ordinary shocks already heat filaments. Use this only as an extra term after WHIM is subtracted.

## 4. How a length can stay “7” while the universe expands

Catalogues quote comoving \(h^{-1}\,\mathrm{Mpc}\). A raw physical product of time grows.

SBT-compatible locks:

- define \(\mathcal K\) and \(\ell_C\) on comoving charts from the start,
- lock the write-clock \(n\) to expansion so occupation gradients stretch with \(a\) and then exhaust at fixed comoving reach,
- conformal exhaustion as a bound on comoving optical depth of the average.

Without one lock, “7” is today’s snapshot.

## 5. Ranked guess (not a vote to lock)

1. **\(\ell_C\) of \(\mathcal K_{ij}\)** — fewest new objects; already required for domain dark matter.  
2. **Shear from \(V_{\rm orb}^{(i)}\)** — most SBT-specific kinematics; supplies a reason the number is geometric.  
3. **Twistor-average exhaustion** — same family as (1), different language.  
4. **Substratum occupation gradient** — only if that substratum is chosen for other reasons.  
5. **Phase-7 path** — heat, not the web itself.

The honest present sentence:

> In SBT the few-\(h^{-1}\,\mathrm{Mpc}\) web scale is a candidate coherence length of the inter-domain kernel and/or of embedding shear. It is not a fifth-dimensional radius. The integer 7 is not derived.

The calculation that would promote a candidate to a cause: compute \(\ell_C\) from \(V_{\rm orb}^{(i)}\) and the average that defines \(\mathcal K_{ij}\), in comoving units, with no \(S^1\) of that radius in the action. Then measure the pre-registered fracture statistic in a simulation or in DESI.
