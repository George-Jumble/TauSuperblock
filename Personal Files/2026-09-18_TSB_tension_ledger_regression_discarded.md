## Tension list

Tensions are grouped. Each line is a conflict between two locked claims, or between a locked claim and a measurement, that has not been derived away.

### A. Coupling and impedance

**T1. \(\Phi\) has no TSB value that matches CODATA.**  
Cell hop: \(\Phi_{\mathrm{cell}}=34/31\approx 1.10\).  
5D hop at locked lengths: \(\Phi\in\{8,\,5\times 10^{-39},\,2\times 10^{-116}\}\).  
Target: \(\Phi_{\mathrm{obs}}\approx 0.0146\).  
No graph built from \(\{6,7,8\}\) and no fibre from \(\{\ell_P,r_{\mathrm{M}},R_\tau\}\) lands on the target. The \(\alpha_{\mathrm{fs}}\) attempt remains a named failure.

**T2. Two hops for one U(1).**  
4D tick: \(Z_{\mathrm{hop}}=2h/e^2\).  
5D reduction: \(\alpha=4G/\varphi^2\).  
They cannot be multiplied. They have not been shown to be the same hop in different variables. Until one is chosen, \(\Phi\) is scheme-dependent by \(10^{38}\) or more.

**T3. No locked length is the EM fibre.**  
\(\varphi=\ell_P\Rightarrow\alpha=4\).  
\(\varphi=r_{\mathrm{M}}\Rightarrow\alpha\sim 10^{-39}\).  
\(\varphi=R_\tau\Rightarrow\alpha\sim 10^{-116}\).  
The number that works inside the derived prefactor, \(23.41\,\ell_P\), is not in the triple. That is a missing length, not a rounding error.

**T4. \(e\) never emerges.**  
Every impedance written so far is \(\mathrm{R_K}\) times a dimensionless \(\Phi\). \(e\) is inserted by SI. TSB has not produced \(e\) from geometry.

### B. Scales

**T5. Three lengths, two compactifications.**  
The kinematics notes compactify on \(R_\tau\). The clock notes compactify on \(r_{\mathrm{M}}\). The 5D Maxwell term wants a Planckian fibre. One 5-manifold does not have three independent circle radii unless those circles are different factors. The factorisation is named, not derived.

**T6. \(G_4\) is assigned twice.**  
KK reduction: \(G_4=G_5/(2\pi\varphi)\).  
TSB gravity: \(G_4\) is a time average over six domains and bounce deposits. Using both for the same \(G_4\) is double counting. Which formula owns the measured Newton constant is open.

### C. Speeds and \(E_8\)

**T7. Two objects named \(\langle\gamma\rangle_6\).**  
Quark-increment average: \(\langle\gamma\rangle_6\approx 1.37\times 10^4\) (top-dominated).  
Unification PDF: \(M_{\mathrm{eff}}^{p-k}\) uses a symbol \(\langle\gamma\rangle_6\) to reach \(313.1\,\mathrm{MeV}\) from a Planck–Kerr average. Those cannot be the same number without a new derivation. They have been kept apart.

**T8. Linear \(E_8\) does not emit the mass hierarchy.**  
Root projection onto a coordinate 4-plane has radii \(\{0,1,\sqrt{2}\}\) only. \(E_6\) weight lengths run from \(1\) to \(2.12\). Quark \(\gamma_i\) run from \(1\) to \(8\times 10^4\). The hybrid (angles from \(E_6\), speeds from PDG) is an integration, not a projection-derivation. Calling the PDG sextet “the \(E_8\) eigenvalues” is still false.

**T9. Domain names versus flavours.**  
Book outline: Prime, Strange, Charm, Bottom', Top', Beauty'.  
Increment map: \(u,d,s,c,b,t\).  
Down is missing from the outline list; beauty/bottom collide. The Dynkin assignment \(\omega_1\to u,\ldots,\omega_3\to t\) is a named discrete choice of size four inside length classes, not a theorem.

**T10. Current masses versus TEP.**  
Scheme A uses PDG current-quark masses with \(m_u\approx 2.16\,\mathrm{MeV}\).  
The clock is \(\hbar c/313\,\mathrm{MeV}\).  
Constituent control (\(m_u\sim 336\,\mathrm{MeV}\)) changes \(\beta_d\) from \(0.89\) to \(0.15\). The theory has not said which mass scheme the domains couple to.

### D. Cosmology already constrained

**T11. Dilution of \(n_{\mathrm{M}}\) is not live.**  
If \(\xi=\mathcal{O}(1)\) and \(n_{\mathrm{M}}\propto a^{-3}\), clocks give \(|\xi|\lesssim 5\times 10^{-9}\). Branch B at order-unity susceptibility is dead. Branch A (nucleation, constant proper density) remains. This is a tension that has been *resolved toward A*, listed so it is not reopened as if free.

**T12. Clock lock versus 5D null geodesic.**  
Tick lock: \(\Delta t_\tau=2r_{\mathrm{M}}/c\) (diameter).  
Fibre null geodesic at rest in 4D: \(c\Delta t=\varphi\Delta\theta\).  
Those agree only if \(\varphi\Delta\theta=2r_{\mathrm{M}}\). For \(\varphi=r_{\mathrm{M}}\) that is \(\Delta\theta=2\), not \(\pi\) and not \(2\pi/7\). The chord factor \(\alpha\in\{2,2\pi,2\pi/7\}\) and the 5D angle have not been identified.

### E. Numerology that must stay out

**T13. Adjacent numbers that are not identities.**  
\(\log_7(r_{\mathrm{M}}/\ell_P)\approx 23.18\) versus \(\varphi_{\mathrm{EM}}/\ell_P\approx 23.41\).  
\(7\pi\approx 21.99\) versus \(23.41\).  
\(960/7\) versus \(137\) (already flagged, \(778\,\mathrm{ppm}\)).  
None of these is promoted. They are logged as rejected coincidences.
