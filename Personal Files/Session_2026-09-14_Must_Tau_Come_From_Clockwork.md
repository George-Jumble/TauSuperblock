## 2. Two ways to “put everything in order”

Then yes: you need a map

\[
\{\Phi_1,\ldots,\Phi_8\}
\;\longrightarrow\;
\tau
\]

**Key:** left side = named octonion / \(G_2\) letters only; right side = a length. Empty Mpc on the left. Until that exists, \(\tau\) is Gatlin input and the comb is optional baggage.

**B. \(\tau\) is demoted.**  
Order the theory as: clockwork + \(\Phi_7\) + \(f(Z)\) on \(\mathbb{S}_{\mathrm{SB}}\) + \(E_g\) as dressing. Survey \(7\,h^{-1}\mathrm{Mpc}\) is a later lattice hypothesis, not a load-bearing output. Then you do **not** have to derive \(\tau\) first.

This thread already runs on B unless you re-promote \(\tau\).

## 4. Recommended order of work

1. Write \(\Phi_7\) (and the other seven letters) as explicit matrices.
