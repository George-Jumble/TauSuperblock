## 0. Verdict

**The node mass is an input. It does not come out of the choke.**

A cluster at a web node pinches a plate gap by a fraction about \(10^{-44}\). That cannot select a mass. The mass variable on the web is the node mass itself, measured, not derived from \(L\).

---

## 1. Complete key

| Symbol | Meaning |
|--------|---------|
| node | Intersection of filaments. A cluster. |
| \(M_{\rm node}\) | Mass of that cluster. Input. |
| \(R\) | Distance from the node to the gap. |
| \(L\) | Plate separation. Higgs-depth value \(1.89\times 10^{-18}\,\mathrm{m}\) used as the example. |
| \(r_s=2GM/c^2\) | Schwarzschild radius of the node. |
| choke | Fractional closure of order \((r_s/R)(L/R)\). |

---

## 2. Estimate

A node of \(10^{15}\,M_\odot\) at \(1\,\mathrm{Mpc}\):

\[
\frac{r_s}{R}\approx 9.6\times 10^{-5},
\qquad
\frac{r_s}{R}\frac{L}{R}\approx 5.9\times 10^{-45}.
\]

**Key.** \(r_s\): \(2.95\times 10^{18}\,\mathrm{m}\) for that mass. \(R=1\,\mathrm{Mpc}\). \(L=1.89\times 10^{-18}\,\mathrm{m}\). The density shift is four times the fractional closure, about \(10^{-44}\). Undetectable, and not an equation for \(M_{\rm node}\).

Solving the choke for mass would require a measured \(\delta L\). None is in the notes. The web’s mass variable remains the node mass, a survey input. Filament mass per length is a second input. Neither is the floor protocol \(309.3\,\mathrm{MeV}\).
