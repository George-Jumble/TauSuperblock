## 4. What would constitute a non-breaking derivation

An acceptable derivation after any permitted release must still:

1. Use only quantities consistent with the essential locks.  
2. Produce \(n_s\) inside the current observational window without a free efficiency.  
3. Respect residual \(L=0\) for the unbound CMB sector.  
4. Not restore a metric fifth dimension.

The constructive routes already listed (transfer operator of the \(\Phi_7\to\Phi_8\) bounce, hard-wall storage kernel, or a justified slow-roll sector) remain the viable paths. None of them requires release of an essential lock. Release of the non-identification of \(\alpha\) is optional and useful only if the resulting formula matches data.

**Plain language**: We can stop saying “α is not the tilt” if and only if we first derive a formula that turns α (or the clock) into a number that actually agrees with the measured lean. Simply declaring them equal does not agree with the data, so that particular release is not helpful by itself.

## 5. Conclusion

No essential lock can be released while maintaining the integrity of the framework and consistency with laboratory and cosmological physics. Among relaxable items, the only one whose release is potentially relevant is the non-identification of the arithmetic anomalous dimension \(\alpha\) with the tilt; that release is permissible but insufficient unless a parameter-free operator is subsequently shown to reproduce the observed \(n_s\). The primary task remains construction of that operator, not the removal of a lock.

**Plain language**: The framework’s core rules do not have to be broken to try to calculate the CMB spectral index. The calculation itself has not been completed; loosening the non-essential “do not equate α to the tilt” rule only helps after the math produces the right number.
