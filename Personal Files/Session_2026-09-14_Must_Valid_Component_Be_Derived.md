# Session 2026-09-14 — Must a valid cosmological component be derived?

**Question:** If \(\tau\) is a valid piece of the cosmology, should the rest of the framework be able to derive it?

**Answer:** That is required only if the framework claims to be **complete** in dimensionful scales. Validity of the component does not, by itself, force a derivation.

## 2. Two different “shoulds”

**Validity.**  
A scale can be a real part of the cosmology because it is measured or because it organizes data. \(\Lambda\), neutrino masses, and the baryon asymmetry are valid cosmological components. They are not derived from the Standard Model plus GR. Nobody treats that as proof they are unreal.

**Completeness.**  
If \(\mathcal{F}\) is advertised as a closed algebraic cosmology with no free IR lengths, then every extra length — including \(\tau\) — **must** come from \(\mathcal{F}\) times one unit \(U\):

\[
\tau = F(\Phi_1,\ldots,\Phi_8)\,U.
\]

**Key:** \(F\) = dimensionless function of the letters only; \(U\) = the single dimensionful seed.

That is the zero-parameter claim. Failure to produce \(\tau\) does not kill \(\tau\) as an observable. It kills the claim that \(\mathcal{F}\) already contains \(\tau\).

## 3. What follows for TSB

- You may hang topology on \(\tau\) and keep a valid phenomenological cosmology.  
- You may also demand a derivation, but that is an extra ambition.  
- Those two programs must not be blurred: a hook is not a derivation, and an underived hook is not an invalid hook.

If the aim is completeness, the next job is still \(\{\Phi\}\to\tau\) with empty Mpc on the left. If the aim is a working cosmology, \(\tau\) can stay an input and \(\mathcal{F}\) is judged on what it predicts *besides* \(\tau\).
